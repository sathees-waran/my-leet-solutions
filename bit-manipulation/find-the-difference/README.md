# Find the Difference

## Problem  [LeetCode Link](https://leetcode.com/problems/find-the-difference/)

You are given two strings `s` and `t`. String `t` is generated by random shuffling string `s` and then adding one more letter at a random position. Return the letter that was added to `t`.

**Example:**
Input: s = "abcd", t = "abcde"
Output: "e"

## Approach

*Since every character in `s` has a matching pair in `t` except the extra one, XOR-ing all characters cancels out the pairs and leaves only the added letter.*

1. Initialize `ans` to 0.
2. Traverse `s` and XOR every character into `ans`.
3. Traverse `t` and XOR every character into `ans`.
4. Since XOR-ing a character with itself results in 0, all matching pairs cancel out.
5. The only character left un-cancelled in `ans` is the extra letter added in `t`, which is returned.

## Complexity

- **Time Complexity:** O(n) — each character in `s` and `t` is visited exactly once.
- **Space Complexity:** O(1) — only a single character variable is used regardless of input size.
